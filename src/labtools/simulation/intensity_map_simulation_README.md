# Intensity-map simulation

The maintained guide is `docs/intensity-map-simulation.md` in the repository.

Quick start:

```powershell
uv run labtools simulate intensity-map --points 5
uv run labtools simulate intensity-map --gui
```

The original module command remains supported. Only the map mirror, gate and
counter are synthetic; output is development data, not a physical measurement.
Do not rerun the historical simulation installer on the refactored source tree.
